Simulation Parameters

What do these metrics mean?
Sequential time
Time taken by a single-threaded loop over all particles × all steps.
Parallel time
Time taken when the particle loop is distributed across multiple OpenMP threads.
Speedup
Sequential time ÷ Parallel time. A speedup of 2× means the parallel version finished in half the time.
Efficiency
(Speedup ÷ Threads) × 100%. Shows how effectively each thread was utilised. 100% is ideal but rarely achieved due to overhead.
Match
Both implementations must produce identical particle states (within floating-point tolerance). This proves the parallel version is correct.
Bounds
Every particle must remain inside the 100 × 40 simulation area after all steps.
About this project

CrowdSim is a VTU Parallel Computing mini-project that demonstrates shared-memory parallelism using OpenMP in C.

Module 2 — Performance measurement, speedup, and efficiency of parallel programs.
Module 4 — OpenMP directives, #pragma omp parallel for, static scheduling, variable scoping, and thread safety.

The actual computation runs in a compiled C binary. This dashboard displays the real results returned by that program.
